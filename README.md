# 4-bit ALU Design using Verilog HDL

## Overview
This project implements a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL.

## Operations
- Addition
- Subtraction
- Multiplication
- Division
- and
- or
- left shift
- right shift

## Tools Used
- Verilog HDL
- Xilinx Vivado

## Files
- alu.v – ALU design
- tb_alu.v – Testbench
- Waveform.png – Simulation waveform
- Output.png – Simulation output

## Result
The ALU was successfully verified using a Verilog testbench, and the simulation results confirmed the correct functionality of all supported operations.
